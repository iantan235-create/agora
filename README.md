# Agora — Event Management System

Agora is a web-based event and attendance
management system for Taylor's University.

## Technologies
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Local Setup

1. Install MAMP or XAMPP.
2. Place the Agora project folder in htdocs.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Create a database named agora.
6. Import database/agora.sql.
7. Copy pdo.example.php to pdo.php.
8. Update the database connection details.
9. Open the website in your browser.

For our MAMP development environment:
http://localhost:8888/agora/

## Main Features

Student:
- Account registration and login
- Browse and register for events
- Follow student clubs
- View notifications
- Attendance QR codes

Organizer:
- Organizer registration
- Create and edit events
- Manage participants
- QR code check-in
- Attendance reporting
